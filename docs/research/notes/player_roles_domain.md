## 1. Explorer (FSS/DSS, body values, first-discovered/first-mapped, neutron/WD boosting, fuel scooping)

### Takeaway
Explorers decide where to jump next (route/neutron highway), which bodies are worth scanning/mapping/landing on, and when to refuel/repair; everything needed is derivable from journal `FSDJump`/`Scan`/`FSSDiscoveryScan`/`SAAScanComplete`/`FuelScoop`/`JetConeBoost` plus Status.json fuel flags, using the (community-derived, stable since 3.3) scan-value formula and the jump-range formula. Spansh (neutron/galaxy plotter), EDSM (system/body "was discovered" checks) and Canonn/EDAstro supply route and "interesting body" data.

### Cited Findings
**Decisions**: pick next system (neutron/WD jet-cone, ELW/WW/terraformable spotting); scan with FSS vs. skip; map (DSS) or not (payout vs. time); land for exobiology/geology/Guardian; when to scoop vs. jump; when to sell data (data lost on ship destruction); keep fuel >= safe level for next hop.

**Real-time information**: honk progress (`FSSDiscoveryScan.Progress`, `BodyCount`), `FSSAllBodiesFound`, estimated payout per body (base / first-discovered / first-mapped / efficiency), "was discovered/mapped" flags (`Scan.WasDiscovered`, `WasMapped`), signals (`FSSBodySignals` Biological/Geological counts; `SAASignalsFound`), DSS probe count vs. efficiency target, jump range with current mass/fuel, fuel used vs. max per jump, scoop rate/time to full, heat, FSD supercharge state, unsold data total (sum of `Scan` values since last `SellExplorationData`/`MultiSellExplorationData`), distance to next neutron star, number of jumps remaining (`NavRoute`).

**Journal events** (fields in manual): `FSDJump` (JumpDist, FuelUsed, FuelLevel, BoostUsed, StarSystem, SystemAddress, StarPos), `StartJump`, `NavRoute`/`NavRouteClear` (route file NavRoute.json), `FSDTarget`, `FSSDiscoveryScan` (Progress, BodyCount, NonBodyCount), `Scan` (ScanType Basic/Detailed/NavBeacon/NavBeaconDetail/AutoScan; PlanetClass, TerraformState, MassEM, StellarMass, StarType, Landable, Materials, Volcanism, Atmosphere, WasDiscovered, WasMapped), `FSSAllBodiesFound`, `FSSBodySignals`, `SAAScanComplete` (ProbesUsed, EfficiencyTarget), `SAASignalsFound`, `FuelScoop` (Scooped, Total), `JetConeBoost` (BoostValue), `SellExplorationData`/`MultiSellExplorationData` (BaseValue, Bonus, TotalEarnings), `CodexEntry` (IsNewEntry, VoucherAmount), `Touchdown`/`Liftoff`, `ScanOrganic`. Source: [Journal manual Exploration](https://elite-journal.readthedocs.io/en/latest/Exploration.html) and [Travel](https://elite-journal.readthedocs.io/en/latest/Travel.html). Status.json flag bits: Supercruise(16), ScoopingFuel(2048), FsdMassLocked(65536), FsdCharging(131072), FsdCooldown(262144), LowFuel<25%(524288), OverHeating(1048576), IsInDanger(4194304), Hud in Analysis mode(134217728), fsdJump(1073741824); fields Fuel{FuelMain,FuelReservoir}, Cargo, Balance, Destination{System,Body,Name}, LegalState — [Journal manual Status File](https://elite-journal.readthedocs.io/en/latest/Status%20File.html)
- Note: a basic scan (no DSS fitted) of a planet omits atmosphere, volcanism, materials, TerraformState etc. (only name, class, orbit, mass, radius, gravity) — [Journal manual Exploration](https://elite-journal.readthedocs.io/en/latest/Exploration.html)

**Scan-value formula (EDDiscovery implementation of the Frontier-forum "Exploration value formulae"; applies from game v3.3 onward; a few exotic cases are marked "not confirmed in game" in the code)** — [EDD ScanEstimatedValues (EstimatedValues.cs)](https://github.com/EDDiscovery/EliteDangerousCore), referenced forum thread https://forums.frontier.co.uk/showthread.php/232000-Exploration-value-formulae
- Star: `value = k + m*k/66.25` with m = stellar mass (solar masses); k = 14057 white dwarfs (D, DA, DAB, DAO, DAZ, DAV, DB, DBZ, DBV, DO, DOV, DQ, DC, DCV, DX), 22628 neutron star (N) and black hole (H), 33.5678 supermassive black hole (unconfirmed), 1200 all other stars. First-discovered bonus x2.6 (stars have no mapping).
- Planet/moon: `base = max( k + k * q * M^0.2 , 500 )` with q = 0.56591828 and M = MassEM (Earth masses). k by class: Earth-like world 64831+116295 = 181126 (always terraformable); water world 64831 (+116295 if terraformable); ammonia world 96932; Sudarsky class I gas giant 1656; Sudarsky class II gas giant and High-metal-content body 9654 (+100677 if terraformable); metal-rich body 21790 (+65631 if terraformable); everything else (rocky, rocky ice, icy, class III-V GG, etc.) 300 (+93328 if terraformable).
- Multipliers on `base` (planets/moons): first-discovered only (FSS) = base x 2.6; mapped, already discovered+mapped by others = base x 3.3333333; first-mapped but not first-discovered = base x 8.0956; first-discovered + first-mapped = base x 3.699622554 x 2.6; efficiency bonus (map within the DSS probe "efficiency target") = x1.25 on mapped values; Odyssey bonus `v + max(0.3*v, 555)` applied to mapped values when playing Odyssey (EDD `Ody()`); an FSS-only scan yields `base` (x2.6 if first discovered) and is paid at the Universal Cartographics sale.
- Pre-3.3 formulas are also in the code (v2.2 and 3.2 variants), only needed for old-journal replay.

**Jump-range / fuel formulas** — [Coriolis Calculations.js](https://github.com/EDCD/coriolis/blob/develop/src/app/shipyard/Calculations.js), [FSD wiki](https://elite-dangerous.fandom.com/wiki/Frame_Shift_Drive), [FSD (SCO) wiki](https://elite-dangerous.fandom.com/wiki/Frame_Shift_Drive_(SCO))
- Jump range (ly) = `( min(fuelOnBoard, maxFuelPerJump) / fuelmul )^(1/fuelpower) * optmass / totalMass + guardianBoost` where totalMass = hull + modules + cargo + fuel (main tank + reserve; Coriolis adds reserve tank capacity), `optmass` and `maxfuel` are per-FSD (engineering changes optmass/maxfuel), `fuelmul` = linear constant (standard FSD: A 0.012, B 0.010, C 0.008, D 0.010, E 0.011 t; SCO FSDs: A 0.013, B/C/D 0.012, E 0.008), `fuelpower` by class 2..8 = 2.00, 2.15, 2.30, 2.45, 2.60, 2.75, 2.90. Fuel needed for a jump of distance d: `f = fuelmul * (d * totalMass / optmass)^fuelpower` (wiki writes `f = r*(d*mShip/mOpt)^p*1e-3` with r in 8..13).
- Guardian FSD Booster (flat range, class 1-5): +4.00, +6.00, +7.75, +9.25, +10.50 ly; unlock needs Guardian tech-broker materials (1 Guardian Module Blueprint Fragment, 21 Guardian Power Cell, 21 Guardian Technology Component, 24 Focus Crystals, 8 HN Shock Mount) — [Guardian FSD Booster wiki](https://elite-dangerous.fandom.com/wiki/Guardian_Frame_Shift_Drive_Booster)
- FSD Injection (Synthesis): +25% / +50% / +100% range for one jump (grade 1/2/3); supercharge cannot stack with injection — [FSD wiki](https://elite-dangerous.fandom.com/wiki/Frame_Shift_Drive), [FSD Supercharging](https://elite-dangerous.fandom.com/wiki/FSD_Supercharging)
- Supercharge (jet cone with scoop): neutron star x4 (+300%), white dwarf x1.5 (+50%) per the Supercharging and SCO wiki pages; the FSD page still says x1.25 for WD (conflict; treat 1.5 as current). Mk II SCO FSD (size 8, Caspian only, since 2 Dec 2025): neutron x6 (+500%), WD x3 (+200%), and no 1% FSD damage when supercharging. Charge persists until the next jump (survives scooping, docking, logout). Journal: `JetConeBoost.BoostValue`; `FSDJump.BoostUsed` — [FSD (SCO) wiki](https://elite-dangerous.fandom.com/wiki/Frame_Shift_Drive_(SCO)), [Supercharging](https://elite-dangerous.fandom.com/wiki/FSD_Supercharging), [4.3.0.0 notes](https://www.elitedangerous.com/update-notes/4-3-0-0)
- SCO (supercruise overcharge) is a supercruise boost mode: heavy fuel use, heat, control interference; emergency drop on fuel exhaustion damages modules; SCO-designed ships include Python Mk II, Mandalay, Corsair, Caspian and the upcoming Anaconda Mk II — [FSD (SCO) wiki](https://elite-dangerous.fandom.com/wiki/Frame_Shift_Drive_(SCO)). Status.json has no documented SCO flag in the manual I read; heat/fuel/Pips are the observable proxies (Gap).
- Data sources: Spansh galaxy/neutron router and body search (https://spansh.co.uk), EDSM systems/bodies (https://www.edsm.net/en/api-system-v1), EDAstro (https://edastro.com), Canonn for biological/Guardian/POI data; API specs are covered by other researchers.

### Inferences
- A killer explorer widget = "unsold data value" (sum of `Scan` estimates using WasDiscovered/WasMapped flags and the Odyssey bonus) + "worth mapping?" (value x3.33 vs time) + live jump range using `Loadout` (module list incl. engineering) and Status Fuel/Cargo.
- The `Loadout` event carries FSD OptimalMass/MaxFuelPerJump/FuelCapacity and `UnladenMass` (Journal manual Startup) so no external ship database is strictly needed for range; Coriolis/EDSY data only for what-if fits.

### Gaps

- Spansh/EDAstro per-endpoint parameters not re-verified here.

## 2. Exobiologist (species values, clonal colony distance, predicting species from body properties)

### Takeaway
Exobiology is the most "real-time" Odyssey role: the app must track the 3-sample cycle (Log -> Sample -> Analyse) per species, the genus-specific minimum distance to the previous sample (clonal colony range, CCR) using Status.json lat/long, and the unsold payout (fixed per-species value; x5 total if First Logged). Prediction of which species can exist on a body is a rule problem (atmosphere type, gravity, temperature, pressure, volcanism, materials, parent star type, plus nebula/Guardian proximity) solved by open rule files in SrvSurvey and Canonn's empirical stats.

### Cited Findings
- Sampling cycle: `ScanOrganic` events with ScanType Log (1st scan), Sample (2nd), Analyse (3rd, completes), fields Genus, Species, Variant (+_Localised), SystemAddress, Body (BodyID); payout event `SellOrganicData` {MarketID, BioData[{Genus, Species, Variant, Value, Bonus}]} — [Journal manual, New in Odyssey](https://elite-journal.readthedocs.io/en/latest/New%20in%20Odyssey.html). Biological signals are announced by `FSSBodySignals` (Signals Type "$SAA_SignalType_Biological;" Count) and, after DSS, `SAASignalsFound` (Signals + `Genuses` list) — [Journal manual Exploration](https://elite-journal.readthedocs.io/en/latest/Exploration.html); `CodexEntry` carries Category Biology and VoucherAmount.
- Payout rules: Vista Genomics redemption values are fixed per species; samples that qualify as "First Logged" reward 5x (base + 400% bonus) — the wiki text conflicts internally ("x4 bonus on top" vs "5x"); journal `Value`/`Bonus` fields give the true split — [Exobiology Sample Values wiki](https://elite-dangerous.fandom.com/wiki/Exobiology_Sample_Values_and_Details), [Exobiologist wiki](https://elite-dangerous.fandom.com/wiki/Exobiologist). Data is lost if the ship is destroyed before selling at Vista Genomics (so "unsold value at risk" is a key HUD number). Organic Sampler scanning range was raised from 75 m to 750 m in 4.2.1.0 (29 Sep 2025), and the Nomad SLV (4.4.0.0, 30 Jun 2026) carries a Mk II Biological Scanner ("detects biological signatures" from the cockpit) — [4.2.1.0 notes](https://www.elitedangerous.com/update-notes/4-2-1-0), [4.4.0.0 notes](https://www.elitedangerous.com/update-notes/4-4-0-0).
- Clonal colony range (min distance between the 3 samples of one species), by genus: Aleoida 150 m; Amphora Plant 100; Anemone 100; Bacterium 500; Bark Mound 100; Brain Tree 100; Cactoida 300; Clypeus 150; Concha 150; Crystalline Shard 100; Electricae 1000; Fonticulua 500; Frutexa 150; Fumerola 100; Fungoida 300; Osseus 800; Recepta 150; Sinuous Tuber 100; Stratum 500; Tubus 800; Tussock 200; Thargoid biologicals 100 — [Exobiology Sample Values wiki](https://elite-dangerous.fandom.com/wiki/Exobiology_Sample_Values_and_Details)
- Species values (CR, base, wiki table; use as a seed dataset; highest examples): Fonticulua Segmentatus 19,010,800; Stratum Tectonicas 19,010,800; Tussock Stigmasis 19,010,800; Concha Biconcavis 16,777,215; Fonticulua Fluctus 16,777,215; Cactoida Vermis 16,202,800; Clypeus Speculumi 16,202,800 (requires >2500 ls from parent); Fumerola Extremus 16,202,800; Recepta Deltahedronix 16,202,800; Stratum Cucumisis 16,202,800; Recepta Conditivus 14,313,700; Tussock Virgam 14,313,700; Aleoida Gravis 12,934,900; Osseus Discus 12,934,900; Recepta Umbrux 12,934,900; Clypeus Margaritus 11,873,200; Tubus Cavas 11,873,200; Frutexa Flammasis 10,326,000; Osseus Pellebantus 9,739,000; Bacterium Nebulus 9,116,600; cheapest ~1,000,000 (Bacterium Acies/Vesicula/Aurasus, Fonticulua Campestris, Tussock Pennatis/Propagito). Full table incl. atmosphere/temperature/star conditions per species is in the wiki page — [Exobiology Sample Values wiki](https://elite-dangerous.fandom.com/wiki/Exobiology_Sample_Values_and_Details) (secondary source; some cells garbled, Gap: validate against Canonn/SrvSurvey `codexRef`).
- Species prediction from body properties: SrvSurvey keeps one JSON rule file per genus (`bio-criteria/*.json`), each clause `property [min ~ max]` or `property [values]` combined with AND in a tree genus -> species -> variant; properties: body class (Rocky/HMC/Icy...), atmosType, atmosComp (percent composition), gravity, temp, pressure, volcanism, materials present/absent (mats $[..] / ![..]), parent star type (variant colour is determined by star class, e.g. Aleoida Yellow = B, Green = A on rocky, Teal = F, Turquoise = K, Emerald = M, Lime = L, Sage = T, Mauve = TTS, Amethyst = Y, Grey = W, Indigo = D, Ocher = N), distance from arrival, nebula distance, Guardian-site proximity; each species rule carries a "hit count" from real scans — [SrvSurvey bio-criteria readme](https://github.com/njthomson/SrvSurvey/blob/main/SrvSurvey/bio-criteria/readme.md), [aleoida.json](https://github.com/njthomson/SrvSurvey/blob/main/SrvSurvey/bio-criteria/aleoida.json), [BioPredictor.cs](https://github.com/njthomson/SrvSurvey/blob/main/SrvSurvey/BioPredictor.cs). Canonn publishes empirical histograms per codex entry (body types, atmospheres, gravity, distance buckets, counts) — Canonn "biostats" data (https://bioforge.canonn.tech).
- Wiki-level heuristics: Aleoida, Clypeus, Electricae and Recepta need low gravity (wiki: max ~0.27 g), Bacterium can appear on any planet type; Bark Mound only within ~150 ly of a nebula centre; Electricae only on Icy bodies with He/Ne/Ar atmosphere, near A-type or white dwarf stars; Brain Trees (except Roseum) need an Earth-like/water-life gas giant in system; Crystalline Shards need >12,000 ls and a life-bearing world in the system; Amphora Plant needs an A-type parent star — [Exobiology Sample Values wiki](https://elite-dangerous.fandom.com/wiki/Exobiology_Sample_Values_and_Details)
- SrvSurvey's three headline functions (organic scans with distance-to-next-sample overlay, ground-target tracking, Guardian sites) show what a good on-foot/SRV HUD does; it reads journal files and tracks lat/long from Status.json — [SrvSurvey README](https://github.com/njthomson/SrvSurvey)
- Status.json `Flags2` bits for on-foot: OnFoot(1), InTaxi(2), InMulticrew(4), OnFootInStation(8), OnFootOnPlanet(16), AimDownSight(32), LowOxygen(64), LowHealth(128), Cold(256), Hot(512), VeryCold(1024), VeryHot(2048), Glide(4096); plus Oxygen, Health, Temperature, SelectedWeapon, Gravity fields on foot — [Journal manual Status File](https://elite-journal.readthedocs.io/en/latest/Status%20File.html)

### Inferences
- Core exobio features: (1) per-sample distance ring/readout (haversine on Status `Latitude/Longitude` and `PlanetRadius`) vs the CCR table; (2) predicted-species list with value-sorted candidates for each biological signal body (rule engine from SrvSurvey JSONs, MIT-style licence to check); (3) "unsold bio value" with x5 first-logged flag derived from `SellOrganicData.Bonus` history/`CodexEntry.IsNewEntry`; (4) landing-spot recommendations (flat vs hills per genus).
- Powerplay "Hand in biological research samples" merits (LYR, PA ethos) mean exobio data now has Powerplay value (see section 3).

## 3. Powerplay 2.0 (merits, ranks, system states, activities)

### Takeaway
Powerplay 2.0 (Ascendancy, 22 Oct 2024) is a weekly-cycle control-score game: merits are awarded immediately for activity types in three target-system kinds (Acquisition, Reinforcement, Undermining); ranks come from cumulative merits (2,000 / 5,000 / 9,000 / 15,000 then +8,000 per rank). A companion needs to (a) classify the current system (target type), (b) tell the player which of their activities earn merits right here, (c) show merit totals/rank progress, and (d) handle the merit modifiers (markers +25%/+35%, ethos +50%?, reinforcement -20..+30%, undermining +15%).

### Cited Findings
- Rank thresholds: rank 1 = 5 initial weekly missions; rank 2 = 2,000 merits; 3 = 5,000; 4 = 9,000; 5 = 15,000; rank 6+ = +8,000 per rank (rank 10 = 55,000; 20 = 135,000; 50 = 375,000; 100 = 775,000; 100+ = +8,000 per rank). Merits are earned immediately; defecting resets merit progression — [Powerplay wiki](https://elite-dangerous.fandom.com/wiki/Powerplay)
- System states: Uncontrolled -> Expansion (acquisition) -> Contested (conflict) -> Exploited (lowest control) -> Fortified -> Stronghold; one state change per cycle; Exploited needs support from a Fortified (20 ly) / Stronghold (30 ly) system; home system always Stronghold and cannot be reinforced/undermined; control scores decay each weekly turn but not below 25% of their state (Trailblazers 3.4, 3 Jul 2025) — [Powerplay wiki](https://elite-dangerous.fandom.com/wiki/Powerplay)
- Journal: `FSDJump`/`Location`/`CarrierJump` carry `ControllingPower`, `Powers`, `PowerplayState` (InPrepareRadius, Prepared, Exploited, Contested, Controlled, Turmoil, HomeSystem per manual; Fortified/Stronghold in 2.0), and (since March 2025) `PowerplayStateControlProgress`, `PowerplayStateReinforcement`, `PowerplayStateUndermining`, `PowerplayConflictProgress[]`; pledge events `Powerplay` (startup: Power, Rank, Merits, TimePledged), `PowerplayJoin/Leave/Defect`, `PowerplayMerits` {Power, MeritsGained, TotalMerits}, `PowerplayRank`, `PowerplayCollect/Deliver` {Type, Count}, `PowerplaySalary`, `PowerplayFastTrack`, `PowerplayVoucher`; `PowerplayVote` removed in Ascendancy — [EDD JournalPowerplay.cs](https://github.com/EDDiscovery/EliteDangerousCore), [EDD JournalLocOrJump.cs](https://github.com/EDDiscovery/EliteDangerousCore), [Journal manual Travel](https://elite-journal.readthedocs.io/en/latest/Travel.html)
- Activities by target type (earn merits in the right system type; ethos = Power's preferred activities give bonus, "50% suggested"): Acquisition: bounty hunting, holoscreen hacking, power kills, scan megaship datalinks, sell for >=40% profit (bought in supporting system), sell mined resources, sell rares (not bought in AS), Odyssey data transfers/malware, transport Powerplay commodities. Reinforcement: bounty hunting, aid/humanitarian missions, hand in biological samples (LYR, PA) and cartography data, hand in salvage, holoscreen revert, power kills, reboot missions, scan datalinks/ships/wakes, sell for >=40% profit, sell mined resources (mined in same system), sell rares, data transfers, transport Powerplay commodities from a Stronghold. Undermining: commit crimes, aid missions, flood markets with <500 cr/t goods, salvage, hacking, power kills, datalinks, sell mined resources, data transfers, malware, transport Powerplay commodities, plus Stronghold-carrier attacks. Each Power has 1-2 extra "undermining vulnerabilities" (e.g. Archon Delaine: bounty hunting and power kills; Zemina Torval: retrieve specific goods, sell mined resources) — [Powerplay wiki](https://elite-dangerous.fandom.com/wiki/Powerplay) (collated from forum guide by Nowski; last compared 2 Nov 2025)

## 6. Smuggler / Pirate (black markets, stolen goods, hatch breakers, notoriety, fines/bounties, Interstellar Factors) — current rules and December 2026 change

### Takeaway
Today: Black Markets pay ~75% of normal commodity price and exist only where the controlling government tolerates them; illegal/stolen cargo is found by manifest scans (so scan risk and "legal state" are the real-time numbers); bounties attach to the ship, notoriety (0-10) to the commander, Interstellar Factors (IF) clear fines/bounties for a 25% fee only at zero notoriety. All of this is slated to change in the free "Law & Disorder" update in December 2026 (notoriety to ships, no hidden IF, unconfirmed bounties, tiers, cargo-demand piracy). Build this module as versioned rules.

### Inferences

## 11. Fleet carrier owner (tritium, upkeep, jumps, market)

### Takeaway
Owners need: tritium stock vs next jump cost, weekly upkeep vs balance (deducted Thursday 07:00 UTC), jump schedule/cooldown, market/tariff and service state. Journal gives `CarrierStats`, `CarrierJumpRequest`, `CarrierJump`, `CarrierDepositFuel`, `CarrierFinance`, `CarrierBankTransfer`, `CarrierTradeOrder`, `CarrierCrewServices`, `CarrierLocation`, `CarrierDecommission`.

### Cited Findings
- Facts: Drake-class carrier cost 5,000,000,000 cr; base upkeep 5,000,000 cr/week; up to ~30M with all services; max jump range 500 ly; 15-minute minimum preparation (longer in congestion) and 5-minute cooldown after a jump; maintenance 100,000 cr per jump; ~68 t tritium for an empty-hold 500 ly jump (consumption depends on distance and carrier mass incl. services' cargo footprint); upkeep deducted weekly at 07:00 UTC Thursday; debt > 250M for 10 weeks leads to pending decommission (one week to fix); services total capacity 25,000 t shared by crew/services/cargo/ship packs/module packs — [Fleet Carrier wiki](https://elite-dangerous.fandom.com/wiki/Fleet_Carrier)
- Service install/weekly-upkeep/suspended-upkeep/cargo footprint (cr, cr, cr, t): Refuel 40M/1.5M/0.75M/500; Repair 50M/1.5M/0.75M/180; Armoury 95M/1.5M/0.75M/250; Redemption Office 150M/1.85M/0.85M/100; Shipyard 250M/6.5M/1.8M/3000; Outfitting 250M/5M/1.5M/1750; Secure Warehouse (fence) 165M/2M/1.25M/250; Universal Cartographics 150M/1.85M/0.7M/120; Concourse Bar 200M/1.75M/1.25M/250; Vista Genomics 150M/1.5M/0.7M/120; Pioneer Supplies 250M/5M/1.5M/200 — [Fleet Carrier wiki](https://elite-dangerous.fandom.com/wiki/Fleet_Carrier), confirmed by EDD `ServicesData(type, install, upkeep, suspended, cargosize)` "verified with game oct 22" in [EDD Carrier.cs](https://github.com/EDDiscovery/EliteDangerousCore)

### Inferences
- Alerts: balance < next Thursday upkeep, tritium < required (use observed FuelLevel vs `JumpRangeCurr`), jump cooldown timers (DepartureTime + 5 min), weekly decommission countdown; "schedule jump" planner via Spansh Fleet Carrier router.

### Gaps
- The exact tritium-per-jump formula was not found in the wiki or EDD; derive empirically from `CarrierJumpRequest` + `CarrierStats.FuelLevel` before/after, or call Spansh's FC router.

## 12. Colonisation builder (construction depots, required commodities)

### Takeaway
Colonisation left beta in 4.2.2.0 (Nov 2025). Builders need per-depot remaining commodities, construction-point budgets (tier 1/2/3 facilities), claim/lockout timers and weekly-tick timing. The depot journal event is the live data source; Raven Colonial/EDColony-type planners already exist.

### Cited Findings
- Claiming: buy a colonisation beacon claim (25M cr) from a Colonisation Contact within 15 ly of a populated system; one system at a time until the primary port is placed; the primary starport must be fully supplied within a 4-week window; weekly maintenance tick Thursday 07:00 UTC (new facilities can only be placed after the first tick; construction finishes after the tick); FSS reveals available slots; anti claim-sniping lock from 4.2.1.2 (30 min architect-only, then 23.5 h squadron-only) — [System Colonisation wiki](https://elite-dangerous.fandom.com/wiki/System_Colonisation)
- Facility tiers and construction points: Tier-1 (outposts, installations) cost 1 T2 point; Coriolis/Asteroid base cost 3 T2 points and reward 1 T3 point; Ocellus/Orbis/Dodec cost 6 T3 points; each facility changes population, security, tech level, wealth, standard of living, development level; after 4.2.2.0 the initial starport weighs +40% (dev, security, SoL, wealth) / +20% (tech) and later facilities -10% (dev, security) / -20% (SoL) / -25% (tech, wealth) — [System Colonisation wiki](https://elite-dangerous.fandom.com/wiki/System_Colonisation), [4.2.2.0 notes](https://www.elitedangerous.com/update-notes/4-2-2-0)
- Demolition (4.2.1.0): marked facilities removed on weekly maintenance; cancel before then; primary port cannot be demolished; dependent facilities (e.g. security station needs relay station) must go first; commodities put into a cancelled construction are lost; colonisation commodity requirements are visible in the Galaxy/System map — [4.2.1.0 notes](https://www.elitedangerous.com/update-notes/4-2-1-0)
- Architects get weekly credit payments (administration contact), galactic tax above 5M; ownership permanent, no upkeep — [System Colonisation wiki](https://elite-dangerous.fandom.com/wiki/System_Colonisation)
- Journal events: `ColonisationConstructionDepot`, `ColonisationContribution`, `ColonisationSystemClaim`, `ColonisationBeaconDeployed`, `ColonisationSystemClaimRelease`; `Docked`/`Market` at construction sites; Squadron share of contributions — [EDD JournalColonisation.cs](https://github.com/EDDiscovery/EliteDangerousCore)
- Planners/trackers: Raven Colonial (ravencolonial.com; body features, projected economies/stats, logistics), ED Colonisation Planner (journal-based, dependencies, escalating multi-port cost), ED Colonization Helper (carrier + multi-CMDR), EDColony (live depot tracking and trips remaining), Colonization Construction Details spreadsheet (DaftMav), Mega Guide (Mechan) — [System Colonisation wiki Tools/Guides](https://elite-dangerous.fandom.com/wiki/System_Colonisation)

### Inferences
- Killer feature set = depot tracker (remaining tons per commodity, trips for current ship, nearest source market via Spansh/Ardent), multi-commander contribution ledger, construction-point calculator, weekly tick countdown, and system slot/economy preview from FSS data.

### Gaps
- Per-facility commodity requirement lists are large static tables (use Raven Colonial/wiki); they changed in 4.2.2.0 ("updated numbers are reflected in the patch notes") and were not reproduced.

## 13. BGS player (influence, states, tick)

### Inferences

## 17. Implementation cheat-sheet: formulas as pseudo-code and role -> data-source matrix

### Takeaway
Every formula above reduces to a few lines; every role maps to a small set of journal events plus one or two third-party lookups. Version-gate by journal timestamp for: Powerplay merit modifiers (Oct 2024 / Apr-Jul 2025 / Nov-Dec 2025), colonisation numbers (Nov 2025), SCO Mk II multipliers (Dec 2025), surface mining (Sep 2026) and the crime system (Dec 2026).

### Cited Findings (formulas restated; sources are the sections noted)

star_value  = k + m*k/66.25                      # k: WD 14057, N/BH 22628, other 1200; m=StellarMass

first_mapped_only     = base*8.0956
first_disc+first_map  = base*3.699622554*2.6
efficiency            = mapped values * 1.25

# Section 1 - jump range (Coriolis)
range = (min(fuel, maxFuel)/fuelmul)**(1/fuelpower) * optMass/totalMass + guardianBoost
fuel_for_jump(d) = fuelmul*(d*totalMass/optMass)**fuelpower
