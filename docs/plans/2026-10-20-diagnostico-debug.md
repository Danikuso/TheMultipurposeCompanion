## Desviaciones
- D3: "SQL como plantilla" se interpreta como texto SQL parametrizado: se registra `sql_template` (maximo 512 bytes) solo si no hay literales entrecomillados ni numericos sueltos (posible interpolacion); si no, solo `sql_fingerprint`. El redactor revalida la plantilla.
- D3: la importacion historica muestrea (32 lineas completas por archivo, resto agregado en `store.import.batch_committed`) para acotar volumen; el flujo en vivo mantiene verbosidad completa.
- D1: baseline UI tenía dos expectativas obsoletas de rango Maestro; el propietario ya aprobó rangos en inglés el 2026-10-19. Se sincronizan solo esas dos expectativas con Master, como en F3, sin importar el resto de F3. RED observado por el controlador (142 PASS/2 FAIL).
- Validación completa y commits se coordinan con el controlador; ninguna tarea se marca hecha antes de revisión y checks.
- D2b (2026-10-20): por decisión aprobada del propietario, el almacenamiento circular de ficheros JSONL de D2 (32 x 8 MiB, rotación diaria, fragmentos de 1 MiB) se sustituye por una base SQLite separada `debug_logs/diagnostics.sqlite` con una tabla por apartado. Se conservan cola acotada, marcas de pérdida/salida y solo-debug; los fragmentos desaparecen (payload completo hasta 128 KiB, marcador truncado por encima).
