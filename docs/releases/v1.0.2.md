# TMC v1.0.2 — The Multipurpose Companion

## Correcciones

- Corregido el bloqueo al abrir **Panel general** desde cualquier apartado cuando hay una ruta de varios saltos. El panel interpreta ahora los campos reales del diario y permite repetir sistemas en una ruta.
- Añadidas pruebas de regresión para volver al Panel general desde Exploración, Navegación, Nave, Minería y Comercio.

## Mejoras desde v1.0.1

- Comprobación de actualizaciones al iniciar TMC, con instalación opcional desde la aplicación y progreso de descarga.
- Valores de exploración más claros: indicación de cuerpos prioritarios para mapear y del valor adicional previsto; estimación de masa cuando el diario no la proporciona.

## Descargas para Windows

- **TMC-Setup.exe** o **TMC_1.0.2_x64-setup.exe**: instalador de Windows.
- **TMC.exe**: ejecutable portable.
- **Manual_TMC_Comandante.pdf**: manual del comandante.

La compatibilidad oficial con Linux continúa en desarrollo y no forma parte de esta versión.
