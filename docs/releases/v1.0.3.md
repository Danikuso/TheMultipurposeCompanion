# TMC v1.0.3 — The Multipurpose Companion

## Correcciones

- Corregido el desplazamiento vertical de Ajustes: ahora se puede llegar a las opciones de INARA, Frontier CAPI y el resto de la configuración inferior mediante la rueda del ratón o la barra de desplazamiento. Resuelve la issue #3.
- Añadida una regresión de navegador a 1366×768, 1440×900 y 1920×1080 que comprueba el acceso a ambas tarjetas y el regreso al principio.
- La prueba de integración que requiere KokoroTTS instalado queda identificada como opcional; las pruebas ordinarias siguen comprobando el funcionamiento cuando el worker no está disponible.

## Documentación

- Añadida a `AGENTS.md` la regla de versiones `x.y.z`: bugfixes incrementan `z`, funcionalidades incrementan `y` y cambios completos de la aplicación incrementan `x`.

## Descargas para Windows

- **TMC-Setup.exe**: único instalador de Windows; se mantiene este nombre estable para la web y el actualizador.
- **TMC.exe**: ejecutable portable.
- **Manuales del comandante**: cinco ediciones completas de 22 páginas, actualizadas para v1.0.3.
