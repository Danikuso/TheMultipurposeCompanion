01. Descripción Técnica y Funcionamiento Interno

TMC (The Multipurpose Companion) es una herramienta auxiliar de código abierto para Elite Dangerous. Su función es procesar en tiempo real los eventos que el juego escribe en disco y presentarlos en paneles estructurados por actividad (navegación, exploración, exobiología, ingeniería, combate, minería, comercio y gestión de flota).

1.1 Lectura pasiva de archivos del juego

TMC no modifica archivos ejecutables del juego, no lee ni escribe en la memoria del proceso EliteDangerous64.exe y no intercepta tráfico de red del cliente. Toda la telemetría proviene exclusivamente de los archivos estándar generados por Frontier Developments en la carpeta de partidas guardadas:

  • Archivos de diario (Journal.*.log): leídos mediante sondeo incremental por desplazamiento de bytes (byte offset), procesando únicamente las líneas nuevas escritas desde la última lectura sin bloquear el archivo.
  • Archivos volátiles de estado (.json): Status.json (banderas de cabina, combustible, pips, coordenadas planetarias), NavRoute.json (ruta trazada en el mapa galáctico del juego), Cargo.json, Market.json, Outfitting.json, Shipyard.json, ModulesInfo.json, Backpack.json, ShipLocker.json y FCMaterials.json.

1.2 Almacenamiento local y arquitectura

El núcleo en Rust levanta un servidor HTTP y de eventos SSE local (por defecto en 127.0.0.1:47320) consumido por la interfaz gráfica en Tauri 2 (o por un navegador en la red local si el usuario lo habilita expresamente). Los datos históricos, planes de ruta, listas de materiales y credenciales locales se guardan en una base de datos SQLite en modo WAL (tmc.db), evitando pérdidas de estado al cerrar la aplicación.

1.3 Aislamiento automático de la galaxia Legacy

Al abrir cada sesión de diario, TMC inspecciona la versión del cliente registrada en la cabecera Fileheader:

  • Galaxia Live (4.0 / Odyssey / Horizons 4.0): muestra la insignia LIVE 4.0 en la barra superior y habilita las consultas y sincronizaciones en línea configuradas por el usuario.
  • Galaxia Legacy (3.8): muestra el aviso Galaxia Legacy: los datos permanecen locales. En este modo, TMC bloquea automáticamente cualquier transmisión a EDDN, EDSM e Inara, así como el planificador en línea, para no mezclar datos entre ambas galaxias.

02. Instalación, Archivos de Configuración y Arranque

2.1 Requisitos del sistema

  • Windows: Windows 10 o Windows 11 (64 bits) con Microsoft Edge WebView2 Runtime (incluido de serie en sistemas actualizados).
  • Linux: Distribución x64 con webkit2gtk-4.1 para la ventana de escritorio, o cualquier entorno Linux para ejecutar el servidor sin ventana (tmc-headless).
  • Consumo habitual de recursos: ~35–60 MB de RAM para el motor principal (objetivo máximo de diseño < 150 MB con interfaz abierta) y < 1 % de uso de CPU en reposo.

2.2 Procedimiento de instalación en Windows

  1. Descargue el instalador TMC_0.1.0_x64-setup.exe desde la sección Releases del repositorio oficial en GitHub (https://github.com/Danikuso/TheMultipurposeCompanion/releases).
  2. Ejecute TMC_0.1.0_x64-setup.exe y siga los pasos del asistente NSIS para completar la instalación.
  3. Inicie TMC desde el acceso directo del Menú Inicio o Escritorio. Puede abrir TMC antes o después de iniciar Elite Dangerous.
Nota técnica sobre el aviso de Windows Defender SmartScreen Dado que TMC es un proyecto independiente de código abierto y sus binarios no están firmados con un certificado comercial EV de pago, la primera ejecución del instalador en Windows puede mostrar la ventana preventiva «Windows protegió su PC».
Para ejecutar el instalador: pulse en «Más información» y, a continuación, en el botón «Ejecutar de todas formas». También puede verificar o compilar el ejecutable directamente desde el código fuente siguiendo la Sección 12.3.

2.3 Ubicación de archivos de datos y configuración

Elemento Ruta predeterminada en Windows Ruta predeterminada en Linux
Diarios del juego leídos %USERPROFILE%\Saved Games\Frontier Developments\Elite Dangerous\ Prefijo Proton/Wine de Steam detectado o ruta indicada manualmente
Archivo de configuración %APPDATA%\TMC\config.toml ~/.config/tmc/config.toml
Base de datos local SQLite %APPDATA%\TMC\tmc.db (o ruta definida en config.toml) ~/.local/share/tmc/tmc.db

2.4 Bandeja del sistema (System Tray) y cierre de la aplicación

Al pulsar el botón cerrar (✕) de la ventana principal en escritorio:

  • La aplicación no se detiene: permanece en ejecución en la bandeja del sistema (junto al reloj del sistema operativo) para seguir registrando eventos del diario, copiando saltos de ruta y emitiendo avisos de voz si están activos.
  • Al ocultarse en la bandeja, TMC destruye temporalmente la ventana WebView para liberar la memoria gráfica mientras usted juega.
  • Para reabrir la ventana o cerrar completamente el programa, haga clic derecho sobre el icono de TMC en la bandeja del sistema y elija Abrir TMC o Salir de TMC.

2.5 Parámetros de línea de comandos (CLI)

Si sus archivos de diario de Elite Dangerous se encuentran en una unidad o carpeta no estándar, puede pasar argumentos al ejecutable TMC.exe (o en las propiedades del acceso directo):

Argumento Descripción
--journal-dir <carpeta> Fuerza la lectura de diarios y archivos JSON desde la carpeta especificada en lugar de la ruta automática.
--config <archivo> Indica una ruta alternativa para el archivo config.toml.
--ui-dir <carpeta> Sirve los archivos estáticos de la interfaz web desde un directorio personalizado (uso avanzado / desarrollo).

03. Anatomía de la Interfaz y Controles Globales

La interfaz gráfica se divide en tres zonas permanentes: la barra de estado superior (TopBar), el menú de navegación lateral izquierdo (Sidebar) y el área central de paneles.

3.1 Barra Superior (TopBar)

De izquierda a derecha, la barra superior presenta los siguientes indicadores y controles:

  1. Indicador de estado y galaxia: punto luminoso de conexión con el motor local, aviso si El juego no está en ejecución, progreso cuando se están importando diarios históricos (Importando historial: X de Y) e insignia de galaxia (LIVE 4.0 o aviso de LEGACY).
  2. Sistema y modo de vuelo actual: nombre del sistema estelar actual y estado operativo detectado (Atracado, Aterrizado, Espacio normal, Supercrucero, Hiperespacio, A pie, En vehículo de superficie, En caza, En taxi o Multitripulación).
  3. Medidores rápidos de nave: barras de nivel de Combustible, integridad de Casco (%), ocupación de Carga (toneladas actuales / capacidad máxima) y saldo de Créditos.
  4. Control de micrófono (si la asistencia por voz está habilitada): permite activar o silenciar la escucha de consultas por voz.
  5. Interruptor Auto-companion: activa o desactiva el cambio automático de pantalla según contexto.

3.2 Funcionamiento del interruptor «Auto-companion»

  • Activado: TMC selecciona automáticamente la disposición y el panel contextual más pertinente cuando ocurre un evento significativo en el juego (por ejemplo, pasa a Exploración al saltar a un sistema nuevo, conmuta a Exobiología al bajar a pie sobre un cuerpo con señales biológicas, abre Minería al lanzar un dron prospector o pasa a Combate al desplegar armas frente a un objetivo hostil).
  • Desactivado: la aplicación permanece fija en la disposición o módulo que usted haya seleccionado manualmente en la barra lateral, sin realizar cambios automáticos de vista.

3.3 Barra Lateral: diferencia entre «Disposiciones» y «Módulos»

El menú lateral izquierdo cuenta con desplazamiento vertical propio y contiene dos bloques diferenciados, además del botón Ajustes anclado en la parte inferior:

  • Disposiciones (11 vistas combinadas): muestran varios paneles relacionados simultáneamente en una rejilla adaptada a una tarea concreta (por ejemplo, la disposición Exploración combina en una misma pantalla la tira de ruta, el resumen del sistema, el selector de contexto Cuerpos/Exobiología y el planificador). Disposiciones incluidas: Exploración, Nave, Combate, Minería, Comercio, Misiones, Ingeniería, Fleet Carrier, Colonización, Powerplay 2.0 y BGS.
  • Módulos (16 vistas individuales): abren de forma dedicada y a ancho completo todas las herramientas de un único módulo específico: Ingeniería, Panel general, Nave, Navegación, Exploración, Exobiología, Combate, Minería, Comercio, Misiones, Fleet Carrier, Colonización, Powerplay 2.0, BGS, Cuentas y Crimen.

3.4 Paneles desplegables y tablas anchas

  • Resumen y detalle: cada panel muestra en su tercio superior las métricas esenciales y acciones directas. Los listados extensos o desgloses secundarios se abren pulsando el botón Ver información adicional y se pliegan con Ocultar información adicional.
  • Desplazamiento horizontal fijo: en tablas con numerosas columnas (como la tabla detallada de cuerpos celestes o comparativas de mercado), cuando el contenido supera el ancho del panel aparece una barra de desplazamiento horizontal fija en la parte inferior visible del panel, permitiendo desplazarse lateralmente sin necesidad de bajar primero hasta el final de la tabla.

04. Panel General (Dashboard) y Módulo de Nave

4.1 Operación del «Panel general»

El módulo Panel general reúne el estado operativo básico de la sesión en siete tarjetas:

  • Comandante: nombre, saldo de créditos y barras de progreso en rangos de la Federación de Pilotos (Combate, Comercio, Exploración, Soldado, Exobiólogo, CQC) y Superpotencias (Federación, Imperio).
  • Nave y Ubicación: modelo canónico de la nave activa, nombre e identificador de matrícula, alcance de salto actual, coste de recompra (rebuy), sistema estelar, cuerpo celeste más cercano y estación si se está atracado.
  • Estado en vivo: indicadores de telemetría inmediata leídos de Status.json: Escudos, Anclajes de armas, Tren de aterrizaje, Bloqueo de masa, Navegación silenciosa, Recolector de carga y Sobrecarga de supercrucero (SCO).
  • Ruta y Sesión: siguiente sistema en cola con botón Copiar siguiente sistema, saltos restantes, duración de la sesión actual, número de saltos realizados, distancia recorrida en años luz y balance neto de créditos ganados.
  • Alertas: bandeja de avisos activos cuando se detectan condiciones críticas (Combustible bajo, Sobrecalentamiento, Interdicción en curso, Bajo ataque, Daño en el casco, Oxígeno bajo, Salud baja o fallo de módulo).

4.2 Inspección de equipamiento en el módulo «Nave»

  1. Seleccione Nave en la barra lateral. En la cabecera verá la masa en vacío, capacidad de combustible, carga, alcance de salto y coste de recompra.
  2. Utilice las tres pestañas superiores de auditoría rápida según la función que quiera comprobar:
    • Exploración: verifica si la nave lleva instalados recolector de combustible, potenciador FSD Guardian, escáner de superficie detallada (DSS), hangar de vehículos planetarios (SRV) y unidad de mantenimiento automático (AFMU), avisando explícitamente si falta alguno.
    • Combate: resume las armas montadas en puntos de anclaje y contabiliza potenciadores de escudos, lanzadores de señuelos, defensas de punto y disipadores térmicos.
    • Carga y Minería: indica el número de bodegas instaladas, refinería, controladores de drones e inventario de mercancías en bodega.
  3. Despliegue Desglose módulo por módulo para consultar todas las ranuras de la nave. Puede filtrar por Todos, Anclajes, Módulos primarios, Módulos opcionales o Utilidades, o escribir en el cuadro Buscar por nombre o anclaje.... Cada tarjeta muestra clase/calificación, integridad porcentual, estado de encendido, prioridad energética y modificaciones de ingeniería aplicadas (grado y efecto experimental).

05. Navegación y Planificador de Rutas (Spansh)

El módulo Navegación requiere tener activada la opción Consultar servicios online (Spansh, EDSM, Canonn) en Ajustes y encontrarse en una sesión de la galaxia Live 4.0.

5.1 Lectura de la tira superior «Ruta» (RouteStrip)

Presente tanto en el módulo Navegación como en la disposición Exploración, muestra:

  • Tramos inmediatos: Sistema actual, Siguiente salto y sistema A continuación, junto con Saltos restantes y Distancia total.
  • Información estelar del siguiente salto: clase espectral de la estrella, indicador Se puede repostar (clases O, B, A, F, G, K, M) o No se puede repostar, avisos de Estrella de neutrones / Enana blanca, si el sistema consta como descubierto o no en datos públicos y su estado político/seguridad.
  • Copia al portapapeles: pulse el botón de copia junto al nombre del siguiente sistema para copiarlo al portapapeles del sistema operativo y pegarlo con Ctrl + V en el buscador del mapa galáctico del juego. Si activa en Ajustes la casilla Copiar automáticamente el siguiente sistema, TMC copiará el próximo tramo de forma automática cada vez que complete un salto.
Precedencia entre planes de TMC y NavRoute.json del juego Si no hay ningún plan de Spansh activo en TMC, la tira Ruta muestra automáticamente la ruta que usted haya trazado dentro del mapa de galaxia de Elite Dangerous (NavRoute.json). Cuando usted calcula y acepta un plan en TMC, dicho plan pasa a tener prioridad. Si durante el viaje salta a un sistema fuera del trazado, aparecerá la etiqueta Fuera de ruta con dos opciones directas: Recalcular (traza de nuevo hacia el mismo destino desde su posición actual) o Borrar plan (descarta el plan de TMC y vuelve a mostrar la ruta interna del juego).

5.2 Cómo trazar una ruta paso a paso

  1. Abra el panel Planificador de rutas dentro de Navegación o Exploración.
  2. Seleccione el modo de cálculo según el tipo de viaje:
    Modo Parámetros enviados y funcionamiento
    Ruta exacta (Exact Plotter) Utiliza el servicio Exact Plotter de Spansh (/api/generic/route). TMC extrae directamente del último evento Loadout de su nave la masa en vacío, capacidad de los depósitos principal y de reserva, carga actual, parámetros óptimos del motor FSD (incluyendo ingeniería) y el aumento plano del potenciador Guardian FSD, sin necesidad de exportar perfiles desde Coriolis o EDSY.
    Opciones disponibles: Repostar en estrellas escoop (marca con la etiqueta Repostar las paradas de combustible recomendadas) y Usar inyecciones FSD.
    Autopista de neutrones Utiliza el planificador de sobrecarga de conos de estrellas de neutrones de Spansh. Toma el alcance de salto actual de la nave y aplica el valor de Eficiencia (%) (entero entre 0 y 100; un valor menor prioriza menos desvíos laterales, un valor mayor busca más estrellas de neutrones). El valor inicial se configura en Ajustes → Eficiencia predeterminada del planificador (%).
  3. Verifique el campo Origen (por defecto se rellena con su sistema actual) e introduzca el sistema de Destino seleccionándolo en la lista de sugerencias si aparece disponible.
  4. Pulse Calcular ruta. El estado cambiará a «Calculando la ruta…» mientras Spansh procesa el trabajo.
  5. Revise el resumen generado (Distancia total, número de Tramos y tabla de sistemas con distancia por salto e indicación de repostaje) y pulse Aceptar para activar la ruta en cabina.

Comportamiento en sistemas procedimentales no registrados

Si inicia el cálculo desde un sistema del espacio profundo que todavía no existe en la base de datos de Spansh, TMC lee las coordenadas tridimensionales StarPos (X, Y, Z) de su diario local, consulta automáticamente el sistema indexado más cercano mediante /api/nearest y calcula la ruta desde ese punto de referencia sin requerir intervención manual.

06. Exploración Cartográfica y Exobiología

6.1 Selector de contexto en la disposición de Exploración

En la disposición Exploración, el panel principal dispone de un conmutador superior (Panel de contexto) con dos pestañas: Cuerpos y Exobiología. Puede alternar entre ambas en cualquier momento (o dejar que Auto-companion seleccione Exobiología al aterrizar en un cuerpo con señales biológicas).

6.2 Uso del módulo «Exploración»

  • Progreso de escaneo FSS: muestra cuántos cuerpos del sistema han sido descubiertos respecto al total anunciado por el pulso de descubrimiento (honk) y el valor cartográfico estimado acumulado en el sistema.
  • Recomendación de sondeo DSS («Mapear»): TMC compara el valor estimado de mapeo con sondas DSS de cada planeta frente al ajuste Umbral de «Mapear» (cr) definido en Ajustes. Todo planeta que supere dicho umbral (como mundos tipo Tierra, acuáticos, de amoníaco o candidatos a terraformación) recibe un indicador visual de recomendación de mapeo.
  • Tabla de cuerpos del sistema: detalla nombre del cuerpo, tipo, distancia desde la estrella principal (en segundos luz), gravedad superficial, atmósfera, vulcanismo, señales biológicas/geológicas, si es aterrizable y su valor estimado. La altura de la tabla se adapta dinámicamente al número real de cuerpos detectados.

6.3 Uso del módulo «Exobiología» (Odyssey)

Diseñado para el muestreo genético en superficie mediante el escáner del traje Artemis:

  1. Predicción y catálogo por cuerpo: tras escanear un planeta con el FSS o lanzar sondas DSS, el panel lista el número de señales biológicas detectadas y, según las condiciones físicas del planeta (temperatura, gravedad, tipo de atmósfera y estrella), muestra los géneros/especies candidatos junto a su pago base en Vista Genomics (aplicando el multiplicador ×5 cuando el cuerpo no registra pisada previa).
  2. Seguimiento de las 3 muestras y distancia mínima clonal:
    • Al tomar la primera muestra genética (1 / 3) con el traje Artemis, TMC guarda las coordenadas planetarias exactas (latitud y longitud) de ese punto de muestreo.
    • A medida que usted se desplaza a pie, en SRV o en vuelo rasante, TMC calcula en tiempo real mediante trigonometría esférica (usando el radio del planeta y la posición viva de Status.json) la distancia en metros respecto a las muestras ya tomadas de esa especie.
    • Cada género biológico exige una distancia mínima distinta (por ejemplo, 100 m, 150 m, 300 m, 500 m u 800 m). Mientras esté dentro del radio de exclusión, el indicador permanece bloqueado mostrando los metros restantes; al superar la distancia mínima requerida respecto a todas las muestras previas, el indicador cambia a estado listo (verde) para recoger la muestra 2 / 3 o 3 / 3.
  3. Rumbo y valor sin vender: muestra el rumbo en grados para orientarse sobre la superficie y mantiene el sumatorio de datos biológicos pendientes de entrega en cabina.

07. Ingeniería y Gestión de Materiales

El módulo Ingeniería centraliza el inventario de materiales de nave, la taquilla de Odyssey, el estado de los ingenieros, el cálculo de recetas y las propuestas de intercambio.

7.1 Consulta de inventarios y taquilla

  • En el panel Materiales, alterne entre las pestañas Materias primas, Fabricados, Codificados y Taquilla (subdividida en Artículos, Componentes, Consumibles y Datos de Odyssey).
  • Use el campo Buscar material por nombre... para localizar cualquier elemento. Cada fila muestra su grado (G1–G5), existencias frente a capacidad máxima (Tienes / Máx), unidades reservadas por su lista de la compra y una etiqueta MÁXIMO cuando el almacén de ese material está lleno.

7.2 Planificación de mejoras («Ingenierizar un módulo») y desbloqueo guiado

Para calcular qué necesita para modificar cualquier módulo de su nave (esté de serie o ya parcialmente modificado):

  1. En el panel Mi nave modificada, haga clic sobre el módulo que desea mejorar (o abra directamente el panel Ingenierizar un módulo).
  2. Seleccione el Blueprint deseado, el Grado objetivo (G1 a G5) y, si procede, el efecto Experimental.
  3. Ajuste si lo desea las Tiradas por grado (los valores predeterminados para G1–G5 se configuran en Ajustes → Tiradas de ingeniería por grado (G1–G5, 1–10)) y pulse Calcular materiales.
  4. Verificación automática de acceso al ingeniero:
    • Si usted ya tiene desbloqueado a un ingeniero capaz de aplicar ese grado, TMC indica Ingeniero recomendado, su taller, la distancia en años luz y el porcentaje de materiales listos.
    • Si todavía no tiene desbloqueado al ingeniero requerido: TMC no oculta la receta ni muestra un bloqueo vacío; despliega primero el bloque GUÍA DE AYUDANTE — DESBLOQUEO DEL INGENIERO con tres pasos secuenciales (1. Descubrimiento, 2. Invitación y 3. Tarea de Desbloqueo), indicando el progreso registrado en su diario y un botón Copiar sistema para viajar al taller, y justo debajo presenta el bloque MATERIALES REQUERIDOS TRAS EL DESBLOQUEO.
  5. Pulse Añadir a la lista de la compra para guardar ese objetivo en el panel Lista de la compra. Puede añadir varios módulos, reordenar su prioridad (Subir / Bajar) o eliminarlos (Quitar).

7.3 Soluciones de intercambio (Material Traders) y fuentes

  • Panel Intercambios: cuando le faltan unidades de algún material para su lista de la compra, TMC analiza sus excedentes sin reservar de la misma categoría y genera instrucciones directas de canje (Da X de [Material A] y recibe Y de [Material B]) aplicando las tasas oficiales de conversión de los comerciantes del juego (misma subcategoría o cruzada).
  • Localización de comerciantes y brokers: muestra el Comerciante más cercano (de materias primas, fabricados o codificados) y el Broker de tecnología más cercano (Humano o Guardian) indicando estación, sistema, plataforma de aterrizaje y distancia, con botón directo Copiar sistema.

08. Combate, Misiones y Jurisdicción (Crimen)

8.1 Módulo «Combate»

  • Objetivo fijado: al seleccionar y escanear una nave en el juego, muestra el nombre del piloto, modelo de nave, rango de combate, facción, estatus legal (limpio o buscado con recompensa), porcentaje de escudos, porcentaje de casco y salud del subsistema apuntado.
  • Zonas de Conflicto y Combate Anti-Xeno (AX): contabiliza bajas, bonos de combate acumulados en sesión, progreso de bandos en zonas de conflicto y telemetría específica de enfrentamientos contra interceptores Thargoides.

8.2 Módulo «Misiones» y agrupación de masacres

  • Registro de contratos activos: lista todas las misiones aceptadas con su sistema/estación de destino, recompensa y tiempo restante antes de expirar. En misiones de transporte de pasajeros o turismo, compara el pago frente al parámetro Referencia de turismo (cr/al) de Ajustes.
  • Tabla de misiones de masacre por facción: cuando acepta varias misiones de eliminación de piratas dirigidas contra una misma facción objetivo, TMC las agrupa en columnas según la facción emisora. Dado que en Elite Dangerous una baja cuenta simultáneamente para una misión de cada facción emisora distinta (pero en serie si dos misiones provienen de la misma facción), la tabla calcula el número total de bajas necesarias por facción y las bajas restantes para completar todo el lote.

8.3 Módulo «Crimen» (Estado legal y Notoriedad)

  • Multas, recompensas y carga ilegal: desglosa las multas y recompensas activas por jurisdicción y advierte si transporta mercancías marcadas como ilegales o robadas en la bodega.
  • Seguimiento de Notoriedad: muestra su puntuación actual de notoriedad (0 a 10). De acuerdo con las reglas del juego, cada punto de notoriedad tarda 2 horas de sesión activa en decaer; mientras la notoriedad sea mayor que 0, los contactos de Interstellar Factors no permiten saldar recompensas.
  • Búsqueda de servicios neutrales: localiza los sistemas más próximos con servicio de Interstellar Factors (para pagar multas o recompensas con notoriedad 0 sin ser enviado a una nave prisión) y estaciones con Mercado negro activo.

09. Minería, Comercio, Fleet Carrier, Colonización, Powerplay 2.0 y BGS

9.1 Minería

  • Lectura de drones prospectores: cada vez que un dron prospector analiza un asteroide, el panel registra los minerales presentes, su porcentaje de composición, la riqueza de materiales y la presencia de mineral de núcleo (core), resaltando aquellos incluidos en su lista de interés.
  • Métricas de sesión y puntos de venta: calcula la velocidad de refinado en toneladas por hora (t/h), el llenado de bodega y consulta estaciones cercanas donde vender los minerales extraídos.
  • Parámetros en Ajustes: puede añadir o quitar Minerales de interés, fijar el Umbral de valor de minería (cr) y definir el Radio de búsqueda de venta (al, 10–500).

9.2 Comercio

  • Muestra la carga actual en bodega, compara los precios de compra y venta del mercado local (al abrir el mercado de una estación en el juego) respecto a la media galáctica y permite buscar rutas comerciales filtrando por capacidad de carga, tamaño de plataforma de aterrizaje (Mediana o Grande) y antigüedad de los precios recibidos por EDDN (ajustable mediante Radio de datos EDDN (al, 20–500) en Ajustes).

9.3 Fleet Carrier

  • Supervisa el estado de su portaaviones a partir de los eventos CarrierStats, CarrierJumpRequest y FCMaterials: ubicación actual, destino y temporizador de cuenta atrás cuando hay un salto programado, nivel del depósito de Tritio (y reservas adicionales en bodega), distribución de espacio ocupado por servicios/carga/órdenes de mercado, saldo financiero del Carrier y coste de mantenimiento semanal.

9.4 Colonización, Powerplay 2.0 y BGS

  • Colonización: registra el avance de suministro en proyectos de colonización de sistemas, detallando las cantidades entregadas y pendientes de cada materia prima requerida para completar la construcción de la instalación o puerto.
  • Powerplay 2.0: muestra la potencia galáctica a la que está vinculado el comandante, rango actual, méritos ganados durante la sesión y acumulados en el ciclo semanal, así como el estado de control del sistema visitado.
  • BGS (Background Simulation): al entrar en un sistema poblado, lista todas las facciones menores presentes con su porcentaje de influencia, gobierno, lealtad, estados activos/pendientes/en recuperación (Guerra, Elecciones, Auge, Hambruna, etc.) y lleva la cuenta de misiones, bonos o cartografía entregados en la sesión que afectan a cada facción.

10. Cuentas y Sincronización con Servicios Externos

Todas las integraciones con servicios comunitarios o de Frontier son opcionales. Si desea operar TMC de manera 100 % local sin tráfico saliente, desactive en Ajustes el interruptor Consultar servicios online (Spansh, EDSM, Canonn) y mantenga desactivados los interruptores del módulo Cuentas.

10.1 Elite Dangerous Data Network (EDDN)

  1. Abra el módulo Cuentas en la barra lateral.
  2. En la tarjeta Elite Dangerous Data Network (EDDN), active el interruptor Transmisión a EDDN activa.
  3. TMC retransmitirá automáticamente los esquemas públicos de precios de mercado, equipamiento, astillero y saltos estelares (solo en galaxia Live 4.0). No requiere cuenta ni contraseña; su identificador de envío (Uploader ID) se seudonimiza localmente mediante una sal criptográfica aleatoria.

10.2 Elite Dangerous Star Map (EDSM)

  1. Obtenga su nombre de comandante y su clave API en su cuenta de https://www.edsm.net (menú My Account → API Key).
  2. En la tarjeta Elite Dangerous Star Map (EDSM) del módulo Cuentas, rellene los campos Comandante EDSM y Clave API de EDSM.
  3. Pulse Guardar credenciales (quedarán almacenadas de forma persistente en la base de datos local para próximas ejecuciones) y active el interruptor Sincronización EDSM activa. Puede forzar un envío puntual con Sincronizar ahora.

10.3 Inara (InAPI v1)

TMC está registrado en la whitelist oficial de Inara bajo el identificador de aplicación The Multipurpose Companion (TMC) y agrupa automáticamente los eventos en lotes para respetar la cuota oficial (máximo 2 peticiones cada 60 segundos).

  1. Genere su clave personal en https://inara.cz/elite/cmdr-settings-api/.
  2. En la tarjeta Inara (InAPI v1), introduzca su Comandante Inara y su InAPI Key personal.
  3. Pulse Guardar credenciales y compruebe la validez pulsando Probar conexión (debe aparecer Conexión exitosa con Inara).
  4. Active el interruptor Sincronización Inara activa. El panel mostrará los eventos pendientes en cola y el tiempo hasta la siguiente ventana de envío (o puede pulsar Transmitir lote ahora cuando haya cuota disponible).

10.4 Frontier Companion API (CAPI — OAuth2 PKCE)

Permite consultar desde TMC su perfil oficial de Frontier y la lista de naves almacenadas en astilleros remotos de otros sistemas sin que TMC conozca nunca su contraseña de Frontier:

  1. En la tarjeta Frontier Companion API (CAPI), active Integración CAPI activa y pulse Vincular con Frontier Store.
  2. Se abrirá su navegador web predeterminado en la página oficial de autenticación de Frontier. Inicie sesión (con su cuenta Frontier, Steam o Epic vinculada) y autorice el acceso.
  3. Al finalizar, el navegador redirigirá automáticamente a TMC y el estado cambiará a Cuenta vinculada oficialmente. Los tokens se renuevan y restauran automáticamente al reiniciar TMC.
  4. Procedimiento alternativo si el navegador bloquea la redirección local: si su navegador impide volver automáticamente al puerto local tras autorizar en Frontier, pulse en TMC el enlace ¿Problemas de redirección? Pegar URL, copie la dirección URL completa que muestra la barra de direcciones de su navegador tras autorizar, péguela en el cuadro de texto y pulse Completar.
  5. Pulse Actualizar flota para descargar el listado de naves almacenadas en astilleros. Nota: los servidores CAPI de Frontier actualizan la instantánea de naves cuando usted atraca en una estación o abre el menú de Astillero dentro de Elite Dangerous (Live 4.0).

11. Síntesis de Voz (TTS), Asistente Vocal, VoiceAttack y Red Local (LAN)

11.1 Configuración de avisos hablados (Síntesis de Voz / TTS)

  1. Abra Ajustes (abajo a la izquierda) y localice la sección Copiloto de voz y alertas de cabina.
  2. Active el interruptor Activar copiloto auditivo.
  3. Seleccione el Motor de síntesis:
    • Nativo del sistema operativo (Ultraligero): utiliza directamente las voces instaladas en el sistema operativo (SAPI5 / OneCore en Windows). No requiere dependencias adicionales y consume menos de 2 MB de memoria.
    • Motor neuronal KokoroTTS: síntesis neuronal local mediante ONNX. Requiere disponer del entorno Python local con kokoro-onnx y los archivos del modelo Kokoro-82M. Se ejecuta en un proceso auxiliar sin ventana que se suspende automáticamente tras 60 segundos sin locuciones para liberar memoria RAM.
  4. Elija la Voz del copiloto, ajuste los controles deslizantes de Volumen de cabina y Velocidad de locución, y marque únicamente los Canales de aviso activos que desee escuchar (Combate y alertas críticas, Navegación y repostaje estelar, Exploración y exobiología, Minería y prospección, Fleet Carrier).
  5. Pulse 🔊 Probar voz de copiloto para verificar la salida de audio.

11.2 Asistencia por voz (Reconocimiento STT) e integración con VoiceAttack

  • Consultas por micrófono integradas: en Ajustes → Asistencia por voz e integración, puede activar Activar asistencia por voz, seleccionar el modo (Pulsar para hablar (Push-to-Talk) con tecla configurable o Escucha continua) y elegir el motor de reconocimiento (Whisper AI Local offline de ~39 MB o Nativo del navegador / Sistema). Permite consultar por voz: estado general de la nave, siguiente salto estelar, copiar siguiente sistema, nivel de combustible, señales biológicas en el sistema, resumen de materiales fijados, estado legal/multas, factor interestelar más cercano y mercado negro más cercano.
  • Uso con VoiceAttack: si utiliza el programa externo VoiceAttack, diríjase al bloque Integración con VoiceAttack dentro de Ajustes y pulse Descargar perfil (.vap) para guardar el archivo TMC-Copiloto.vap. En VoiceAttack, abra Import Profile y seleccione TMC-Copiloto.vap; los comandos de voz del perfil se comunicarán con la API local de TMC.

11.3 Uso en Tablet o Teléfono mediante Red Local (LAN QR)

Puede abrir la interfaz completa de TMC en una tablet o teléfono móvil para usarla como panel auxiliar táctil sin ocupar espacio en el monitor del ordenador:

  1. Conecte su tablet o teléfono a la misma red local (Wi-Fi / LAN) que el PC donde se ejecuta TMC.
  2. En TMC, abra Ajustes y active el interruptor Acceso por red local.
  3. Aparecerá en pantalla el bloque Código QR de emparejamiento (que incluye la dirección IP local, el puerto y un token de acceso de sesión).
  4. Escanee el código QR con la cámara de su dispositivo móvil y abra el enlace en su navegador web. La pantalla remota recibirá actualizaciones en tiempo real y permitirá interactuar con los paneles (como pulsar Copiar siguiente sistema, que copiará el sistema en el portapapeles del PC principal).

12. Resolución de Problemas, Código Fuente y Soporte

12.1 Tabla de diagnóstico de incidencias frecuentes

Síntoma observado Causa habitual y procedimiento de solución
Aparece «El juego no está en ejecución» o no cargan datos del comandante. Compruebe que existen archivos Journal.*.log en %USERPROFILE%\Saved Games\Frontier Developments\Elite Dangerous\. Si su instalación guarda los diarios en otra ruta o disco, inicie TMC con el parámetro --journal-dir "D:\Ruta\A\Diarios".
El planificador de rutas muestra que no está disponible o que falta el FSD. 1) Verifique en Ajustes que Consultar servicios online está activado.
2) Compruebe en la barra superior que no se encuentra en una sesión LEGACY.
3) Entre con su nave al juego al menos una vez para que el diario emita el evento Loadout con los datos físicos del motor FSD.
La lista de «Flota remota almacenada» en CAPI aparece vacía tras vincular. Frontier CAPI solo devuelve naves almacenadas cuando el servidor de Frontier refresca el perfil en vivo. Entre en Elite Dangerous (Live 4.0), atraque en una estación o abra el menú de Astillero y pulse después Actualizar flota en TMC.
Al escanear el código QR LAN desde la tablet, la página no termina de cargar. 1) Verifique que el perfil de red en Windows está configurado como Red privada y no como Red pública.
2) Autorice a TMC.exe (puerto TCP 47320) en el Firewall de Windows Defender para redes privadas.
3) Compruebe que su router Wi-Fi no tiene activado el aislamiento entre clientes (AP Isolation).
El motor KokoroTTS no emite voz al seleccionarlo. KokoroTTS es opcional y requiere tener instalado Python con el paquete kokoro-onnx y los pesos del modelo local. Si no desea instalar Python, seleccione Nativo del sistema operativo (Ultraligero), que funciona sin dependencias externas.

12.2 Cómo reportar errores o enviar sugerencias (GitHub Issues)

Al ser un proyecto de código abierto, el seguimiento de fallos y propuestas de mejora se gestiona públicamente en GitHub:

  1. Abra Ajustes en la barra lateral de TMC y desplácese hasta la tarjeta Soporte, Feedback y Comunidad.
  2. Pulse el botón Reportar problema o sugerencia en GitHub.
  3. Se abrirá en su navegador el formulario de nueva incidencia en https://github.com/Danikuso/TheMultipurposeCompanion/issues/new con una plantilla técnica prellenada (versión de TMC, sistema operativo e idioma activo, sin incluir ningún dato personal ni identificadores de comandante). Describa los pasos para reproducir el problema y envíe el reporte.

12.3 Auditoría y compilación desde el código fuente

Cualquier usuario o desarrollador puede inspeccionar el código fuente completo o compilar sus propios binarios localmente conforme a la licencia PolyForm Noncommercial 1.0.0. Requisitos: Rust estable (1.90+, edición 2024 con herramientas MSVC en Windows), Node.js 22+ y Tauri CLI v2. 

git clone https://github.com/Danikuso/TheMultipurposeCompanion.git
cd TheMultipurposeCompanion

# 1. Instalar dependencias de interfaz y compilar el frontend (Svelte 5)
npm --prefix ui ci
npm --prefix ui run build

# 2. Ejecutar las suites de pruebas automatizadas (Rust + Vitest)
cargo test --workspace
npm --prefix ui run test

# 3. Compilar el binario Release o generar el instalador NSIS
cargo build -p tmc-desktop --release
cd apps/desktop && cargo tauri build
